# 「知源」智能知识库问答系统 —— 项目成果报告

> 面向：管理层汇报｜日期：2026-09-05

---

## 一、一句话定位

**知源**是一套可私有化部署的智能知识库问答系统：把单位的文档资料（PDF/Word/扫描件/图片）"喂"给它，之后任何人用自然语言提问，系统自动判断是否需要检索资料或联网核验，并给出**有据可循**的答案。

**解决的痛点**：

| 传统方式的问题 | 知源的应对 |
|---|---|
| 资料散落各处，新人找答案靠问老员工 | 统一入库，一问即答，答案附引用来源 |
| 通用 AI（如 ChatGPT）不懂本单位业务，还会"一本正经地胡说" | 只基于已入库资料回答，资料不足会明说"不知道"或转联网核实 |
| AI 回答是黑盒，不知道依据是什么 | 处理过程透明：判定理由、检索阶段、来源编号和耗时可见 |
| 敏感资料上传公网 AI 存在泄露风险 | 资料与检索全在本地/私有环境，仅生成环节调用 API（可替换为私有化大模型） |

## 二、系统概貌

```
员工提问 ──► 意图理解（问知识库？问时效消息？还是闲聊？）
                │
        ┌───────┼────────┐
        ▼       ▼        ▼
  直接回答   联网搜索   知识库检索
                  │     召回粗筛 → 智能精排
                  │        │ 0 命中？
                  │        ▼
                  │    自动换个问法重试
                  └────┬───┘
                       ▼
                大模型生成回答（附编号引用 + 处理过程）
```

**三大功能模块**（均已上线可用）：

1. **智能问答**：多轮对话、会话记忆、处理过程透明、可调节检索深度
2. **资料管理**：多格式上传（PDF/Word/图片/文本）、自动解析识别（含扫描件 OCR）、提取文本可查看核验
3. **知识库管理**：多库隔离（不同部门/业务线各建各的）、向量分布可视化（一图看清资料入库质量）

## 三、项目亮点（区别于"套壳 Demo"之处）

### 1. 答案有据可循，杜绝"AI 幻觉"
采用业界主流 RAG（检索增强生成）架构，回答严格基于检索到的资料；资料不足时明确告知，不编造。**实测无关问题的片段被精排模型以 0.46 vs 0.06 的分数差异精准过滤**。

### 2. 处理过程透明
从"为什么走这条路径"到"用了哪些编号来源"，每一步可观察阶段都在界面上呈现。系统不展示模型内部思维链，只展示用户能核验的依据和执行轨迹。

### 3. 中英文混检能力
采用多语言向量模型，英文提问可直接命中中文资料（实测相似度 0.66，有效命中），适配涉外业务与双语文档场景。

### 4. 资料兼容性实战级
扫描版 PDF 自动 OCR、Word 表格保留、GBK/UTF 编码自动探测——不挑资料，"扔进去就能用"。

### 5. 智能路由链路
闲聊和创作直接回答；知识问题优先结合资料；时效问题按联网开关核验；没有资料且不具时效性的问题由模型直接回答。用户无需关心背后逻辑，也能看到系统选择路径的理由。

### 6. 完全可私有化
向量模型、检索、存储全部本地运行；大模型走 OpenAI 兼容接口，**可无缝替换为内网私有化大模型**，实现全链路数据不出域。

## 四、建设过程（迭代路径）

项目采用"评估 → 闭环 → 深化 → 打磨"四阶段推进：

| 阶段 | 主要工作 | 成果 |
|---|---|---|
| 一、全面体检 | 12 章节技术评估：架构/代码质量/性能/安全/扩展性 | 发现 2 个功能缺陷、9 项风险，形成四阶段改进路线图 |
| 二、跑通闭环 | 数据库部署、API 开发、问答链路打通 | 系统可用，Swagger 自测通过 |
| 三、能力深化 | 入库全链路优化（语义切块/多语言模型/OCR）、会话与记忆、意图智能路由、处理过程展示 | 上文全部亮点能力 |
| 四、体验打磨 | 产品级界面重设计（获好评）、可视化交互修复、多个深层数据/前端 bug 攻克 | 达到可对内交付水平 |

**过程攻坚示例**（体现工程深度）：
- 排查并修复"每次重启数据库被清空"的严重缺陷（数据库元数据类型判断的隐蔽错误）
- 解决大模型本地部署的下载中断、格式兼容、离线加载等一系列问题，文档处理耗时从 5 分钟+ 降至 19 秒
- 定位前端弹窗被父容器动画"锁死"的渲染 bug

## 五、实测性能

| 指标 | 实测值 |
|---|---|
| 文档入库处理 | 约 19 秒（含解析、切块、向量化） |
| 知识库检索 | < 1 秒（召回 0.13s + 精排 0.77s） |
| 完整问答 | 约 30 秒（主要耗时在外部大模型接口，可替换优化） |
| 识别准确率（抽样） | 专业问题/闲聊/时效问题三路路由全部正确；中英文交叉检索均有效命中 |

## 六、部署要求与成本

| 项 | 要求 | 成本 |
|---|---|---|
| 服务器 | 16GB 内存即可运行全部组件 | 一台普通服务器/工作站 |
| 数据库 | Docker 容器（已封装） | 无额外费用 |
| 向量/检索模型 | 本地运行 | 无 API 费用 |
| 大模型 API | OpenAI 兼容接口任选（当前用 SenseNova） | 按 token 计费，轻量模型成本极低 |
| 联网搜索 | Tavily | 免费 1000 次/月 |

**相比采购商业知识库问答产品，本方案零授权费用、数据自主可控、可按需定制。**

---

## 七、下一步规划（建议）

1. **接入私有化大模型**：替换外部 API，实现全链路数据不出域（适配保密要求高的场景）
2. **性能优化**：生成环节延迟降至 10 秒内（换更低延迟模型/流式输出）
3. **权限体系**：按部门/角色控制知识库访问权限
4. **批量导入**：对接网盘/共享目录，历史资料一键迁移
5. **反馈闭环**：用户点赞/纠错回收，持续评估答案质量

## 八、小结

知源系统在**无商业产品采购、零授权费用**的前提下，完成了一套功能完整、过程透明、可私有化部署的智能知识库问答系统建设。项目历经全面评估、闭环打通、能力深化、体验打磨四个阶段，攻克了多语言检索、扫描件识别、智能路由、数据安全等多项工程难题，已达到可对内试运行水平，为知识资产的沉淀与流转提供了可持续的技术底座。
