# 面向 RAG 求职的第一阶段设计

用户于 2026-09-10 确认先做“测试隔离 + 评测集 + 当前检索基线”，并要求扩大面试准备覆盖面。本文件记录已确认范围，后续功能分阶段实施。

## 范围与验收

1. 默认 pytest 使用假凭据，不读取真实服务配置；禁止出网，包含后台任务吞掉异常后的检查。流式接口的长期记忆写回通过受控依赖验证，保留生产行为。
2. 独立合成知识库：12 份原创虚构资料，60 个问题，其中 48 个可回答、12 个无答案；问题带证据原文、参考答案、类别和固定 dev/test 划分。同一资料的问题归同一 split，避免改写问题泄漏。
3. 复用生产解析、切块、BGE-M3 向量化与 ChatService 的候选筛选/重排路径；使用小语料精确余弦检索。明确这不是 pgvector HNSW、路由、查询改写、LLM 答案或端到端性能评测。
4. 比较 dense 与 dense_rerank 两条固定基线，不为改善本次结果调参。参数默认沿用应用：候选 8、返回 4、余弦阈值 0.4、重排阈值 0.3。评测重排失败即报错，不能把向量降级结果冒充重排结果。
5. Recall@K、MRR@K、nDCG@K 仅对可回答问题计算；无答案问题独立报告空检索率（不称为模型拒答率）。输出逐题结果、分组汇总、p50/p95 和失败样例。
6. 记录语料哈希、实现版本/文件指纹、依赖、模型缓存快照、硬件和参数；冷启动与预处理时间分开，单次查询延迟仅作本机观察，不声称并发或生产 SLA。
7. 面试手册覆盖项目讲解、基础原理、效果评测、性能、工程、安全与情景设计，区分已实现、已测量、计划项。不给出“保证应对所有面试”的承诺。

## 文件与边界

`evaluation/dataset.py` 负责校验语料与证据、调用真实切块器；`evaluation/metrics.py` 负责纯指标；`evaluation/run.py` 负责离线模型、评测和报告；`evaluation/data/synthetic_v1.json` 为固定语料。默认测试不加载真实模型，真实模型实验通过 CLI 显式运行。评测无需数据库、LLM 或 Tavily，不写现有上传资料或业务库。

## 验证与风险

用手算样例验证指标、去重、无答案、缺失证据和 split 泄漏；受控向量验证筛选链路；真实模型跑固定基线。若本机模型不可用，记录失败原因，不发布模拟性能。合成小语料可能高估效果，后续需用户复核标注、真实脱敏业务资料和独立测试集；本阶段结果不能表示企业部署质量。
