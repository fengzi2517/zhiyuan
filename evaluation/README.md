# 离线检索实验

固定语料包含 12 份虚构操作手册、24 个实际切块、60 个问题；每个 split 各有 24 个可回答问题和 6 个无答案问题。问题覆盖直接查询、专有编号、近义表达和跨语言检索。参考答案供人工检查，自动指标只使用证据原文映射出的相关块。

## 运行

在项目根目录使用已安装依赖的 Python：

~~~powershell
python -m evaluation.run --model-cache .hf-cache --output evaluation/reports/new-run
~~~

只读取本地 Hugging Face 缓存，不调用 LLM、Tavily，不连接业务数据库。复用 BGE-M3、bge-reranker-base 及应用切块/筛选代码。缺失模型或重排异常会失败，不把降级结果冒充重排结果。使用新的输出目录，避免覆盖旧记录。

## 指标口径

- Recall@K：前 K 个不同块命中的相关块数量 / 全部标注相关块数量。
- MRR@K：首个相关块排名的倒数，无命中为零。
- nDCG@K：二元相关性的折损累积增益，除以理想排序增益。
- 以上三项仅对可回答问题取平均；无答案问题不混入分母。
- 无答案空检索率：无答案问题中没有返回任何资料的比例，不是生成模型的拒答率。
- 延迟包含问题向量化、精确余弦扫描与筛选/重排，不含模型加载、文档编码、数据库、路由、改写或 LLM。每种模式只顺序跑一次，p95 是小样本本机观察，不代表 SLA。

## 已保存基线

[首次固定实验](reports/baseline-v1/summary.md) 运行于 2026-09-10，使用编排改造前的生产代码。报告的源文件哈希是准确版本依据；其中 app 文件可从 Git 提交 7609d11 取得。后续编排改造未重跑本实验，不能把此报告当作改造后的端到端评测。

保留集上，纯向量 Recall@4 为 1.0000，加入重排后为 0.9167；无答案空检索率分别为 0 和 1.0000。当前阈值在该小样本上减少了无答案问题返回资料的情况，同时漏掉部分可回答问题。没有证据支持“加重排一定提高召回率”，也不能据此宣布最优阈值。

语料由 AI 编写并做证据字符串、切块映射和 split 一致性核验，尚需业务人员独立复核。标签按资料分组分配 dev/test；优化只用 dev，方案固定后看 test。反复观察 test 后需另建未知问题集。真实业务、复杂 PDF/OCR、多跳证据与 HNSW 近似召回需另行验证。
